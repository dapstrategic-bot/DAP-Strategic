ก่อนขออนุมัติปล่อยจริง
1. ตรวจ deploymentปัจจุบันและ Git HEADล่าสุด หากมีงานใหม่ ให้ rebase/applyเฉพาะชุดเปลี่ยนนี้บนฐานล่าสุด ไม่ทับงานผู้อื่น
2. ตรวจคำสั่ง Owner: หลักสูตร ราคา 9900→3103 Google Meet5วัน มีบันทึกย้อนหลัง สิทธิ์กลุ่มฟรี ลิงก์Tonrop-2570
3. รับข้อสรุปวันเวลา/สิทธิ์/เงื่อนไขขายที่ยังค้าง หรือคงข้อความจะแจ้งให้ทราบตาม Owner ตัดสินใจ ไม่กำหนดแทน
4. สร้าง commitเฉพาะ scopeใน CHANGESET.json จด commitSHAและ hashชุดส่งมอบ
5. บันทึก deploymentIDที่เป็น Productionก่อนการปล่อยจริงเป็น rollback target ไม่ใช้IDเก่าโดยอัตโนมัติ
6. ตรวจ Production build โดยไม่มี DAP_LOCAL_PREVIEW / NEXT_PUBLIC_DAP_PREVIEW / DONGFUNDA_LOCAL_REVIEW และใช้ environmentเดิมของโครงการ
7. อย่าใช้ buildจาก Previewส่งขึ้น Production เพราะมี noindexและปิด analytics
8. ขอ Ownerอนุมัติชุดไฟล์และ deploymentชัดเจนอีกครั้ง แล้วจึง deploy
